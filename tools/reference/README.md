# 参考截图（WebP q80）

由 `tools/` 下的取景器从**原版 Java 程序离屏渲染**产出，1024×640，
用途是给 web 版做构图、配色、UI 位置的人眼参考。

| 目录 | 张数 | 内容 |
|---|---:|---|
| `01-scene` | 96 | 每个脚本在主角初始坐标处的视口（地图/NPC/主角/宝箱/遮掩层） |
| `02-dialogue` | 159 | 对话框，每组对话在 3 个时间点采样（逐字打印过程） |
| `03-narratage` | 42 | 旁白（7 个脚本 × 6 帧） |
| `04-question` | 22 | 答题：选择框 + 问题框（11 个脚本各 2 张） |
| `05-select` | 9 | 药店 / 装备店 / 战斗 的选择确认框 |
| `06-treasure` | 28 | 宝箱：靠近 + 打开 |
| `07-panel` | 11 | 开始 / 存档 / 药店 / 装备店 / 菜单（含按键切换）/ 结局 |
| `08-battle` | 960 | 16 场战斗，各 300 帧序列**每 5 帧抽 1**（≈500ms/帧） |

## 这批图不是保真基线

验收用的是 Q26 定的**跨端剧本**：同一份剧本在 Java 版和 Web 版各跑一遍，
逐帧算差异。战斗帧在验收时两边都是现场生成的，所以这里只留 1/5 采样
作为"这套动画大概长什么样"的参考。

需要逐帧保真度就重新生成：

```bash
tools/build.sh
java -cp tools/build/classes:jl1.0.jar:mp3spi1.9.4.jar:tritonus_share.jar \
     battle.Shot3 <输出目录> 剧情1.txt 300 100
```

## 已知不覆盖

- 每张是**视口**不是整张地图（大地图 100×80 格只看得到一角；整图见 `maps/`）
- 战斗序列是**取景器驱动输入**打出来的（自动点「击」+ 选敌），
  不是人类玩家的操作顺序
