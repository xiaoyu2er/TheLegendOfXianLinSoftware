# 战斗里的三个菜单画进画布，不用 React

`docs/MIGRATION-PLAN.md` 定的分工是「Pixi 画场景与战斗，React 画 UI（菜单 /
商店 / 装备 / 技能 / 对话框）」。战斗里的指令菜单、技能菜单、药品菜单正好卡在
这条线上——它们是菜单，但长在战斗里。**这三个走 Pixi，是对那条分工的
有意偏离。**

理由是判据：这三个菜单在原版里画的是**按钮贴图**，不是文字排版，而战斗要
逐像素比对。贴同一张图天然一致；用 React 加 CSS 重做，要做到每个像素相等
几乎不可能。

## Considered Options

**React 画，靠截图仍能截到它**。取图走的是 `Page.captureScreenshot` 裁
1024×640，截的是页面合成后的画面，所以 DOM 元素**确实会**被截进去——这条
路技术上通。否掉它的是像素相等这个要求，不是截不截得到。

## Consequences

M3 做独立菜单系统时用 React，与这里不冲突：那批菜单不在逐像素比对的剧本里。
