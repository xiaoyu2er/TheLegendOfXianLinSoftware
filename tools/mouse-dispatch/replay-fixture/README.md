# 三份存下来的原始日志：让 `--replay` 那半判据**不用借鼠标**也能跑一遍

`tools/mouse-dispatch-probe.sh` 真跑一趟要接管物理鼠标十几秒，所以它的对账那半平时
没人跑得起。`--replay` 把对账从「跑一趟」里拆出来：拿存好的 `events*.log` 重新归一化、
重新对账，**一下鼠标都不碰**。三份 fixture 都是 xl-g9w 实跑存下来的
（macOS 24.6.0 + openjdk 17，2026-09-16；一份默认落点，两份 `same-app-window`），
它们钉住的是**三种不同的退出状态**，不是「红绿两面」：

对账分三层，三份 fixture 各钉住一组，**退出码三态、互不共用**：

| 层 | 核的是什么 |
|---|---|
| ① 逐轮 A 对照 | 这一轮到底**量到没量到**（零事件 = 合成事件被丢了，不是「原版收不到」） |
| ② 期望读数 + 轮间 | 读数**对不对、稳不稳** |
| ③ 换落点比对（📐） | 换落点**改没改结论**（只在非默认落点上跑） |

| 退出码 | 含义 |
|---|---|
| `0` | 三层都过 |
| `1` | **有红**：量到了，但读数不对 / A 对照不成立 / 轮间不一致 |
| `3` | **有一层没核成**：不是错了，是没观测到 —— 不许与 `0` 共用 |

```bash
# EXIT=0 —— 默认落点，①② 都过；③ 对默认落点本来就不跑（没有「另一块窗口」要滤）
tools/mouse-dispatch-probe.sh --replay tools/mouse-dispatch/replay-fixture/默认落点四轮

# EXIT=3 —— ①② 都过（12 行、三轮逐字一致），但 ③ 三轮都**没核成**：
#           这份日志录在探针开始写 SAMEAPPCLASS 之前，脚本不知道该滤掉哪块窗口的行。
#           ⚠️ 这个 3 是**故意的**：它证的是 ①②，证不了 ③。
tools/mouse-dispatch-probe.sh --replay tools/mouse-dispatch/replay-fixture/三轮一致 \
  --where same-app-window

# EXIT=1 —— 第 2 轮整轮零事件（当时被别的窗口抢走了焦点）：① 当场点名、② 轮间不一致。
#           有红压过没核成，所以是 1 不是 3。
tools/mouse-dispatch-probe.sh --replay tools/mouse-dispatch/replay-fixture/第二轮被抢 \
  --where same-app-window
```

⚠️ **那个 `3` 是主干验收逮出来的**：它原先是 `0` —— 脚本自己打着「⇒ 没有结论」，退出码却与
「核过且一致」一模一样，而 README 里还写着「退出码 0」。于是「第三层一条都没核成」会被读成
「核过且一致」，**正是这套三层对账本身要防的形状**。修法不是把它变成 `1`（那等于把「没观测到」
说成「有东西错了」，又混一次），而是给它第三个码。

⚠️ 三份日志**都没有 `SAMEAPPCLASS` 行**（录在那之前）。对默认落点那份无所谓 —— ③ 本来就不跑；
对另两份，③ 就是靠这个缺口暴露出来的。下趟借到鼠标时顺手重录 `same-app-window` 那两份，
它们就会从 `3` 变成 `0`（xl-23v，多花约 48 秒）。

`默认落点四轮` 是补给一句话的证据（/code-review Spec 轴提的）：`expected-events.txt` 的头注
写着「xl-g9w 复跑 4 轮、逐行一致、读数未改」，而那句原先**只有陈述、没有可复跑的东西**，
与旁边有 fixture 的 `same-app-window` 不对等。现在它也能被重放一遍。

红的那一份**不是坏数据，是判据的样本**。它守的正是这个脚本原来看不见的两件事
（两条都是 xl-g9w 在真跑里现撞到、再补的）：

1. **A 对照原来只核第 1 轮。** 而被抢的是第 2 轮 —— 旧版只会报「轮间不一致」，
   说不出「这一轮根本没量到」。**「这一轮量到的不一样」与「这一轮什么都没量到」
   是两件事，成因也不同**（前者是读数变了，后者是合成事件被丢了 / 窗口被挡了）。
2. **结论那句话原来无条件打「N 轮之间也逐行一致」。** 于是同一次输出里上面红着
   「第 1 轮与第 2 轮不一致」、下面还跟一句「3 轮之间也逐行一致」。退出码一直是对的，
   **只有那句话是假的** —— 而人读的是那句话。

⚠️ 重放**只写临时目录**，不往这里写东西（否则入库的 fixture 会被自己跑脏，而
「工作区脏了」与「跑完了」在收尾时长得很像）。给 `--out` 可以指定写到哪。

⚠️ 重放证明得了「对账那一段是对的」，证明不了「这一趟真跑量到的东西对」——
后者要真借鼠标跑，判据是三轮逐字一致 + 与期望读数一致 + A 对照。
