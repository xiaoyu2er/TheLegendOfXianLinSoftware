#
# 读数出处：macOS 24.6.0 + openjdk 17，2026-09-16，`tools/mouse-dispatch-probe.sh --yes` 三轮，
# 归一化之后逐字一致。与 expected-events.txt（xl-zs6 的 A / B / B2 / C 四组）分成两份，是因为
# 两份的出处与限定不同；两份对不上都算回归，退出码都是 1。
#
# 序列（drive.swift 的 D 组，分六段打标）与**每一段的实测**：
#   D0 面板里按左，起 grab          → PRESSED btn=1 mex=0x400 src=start.StartPanel xy=600,300（下面第 1 行）
#   D1 拖出窗口（起 grab 那只键按着）→ 12 条 DRAGGED btn=1 mex=0x400 src=start.StartPanel，
#                                     xy 一路到 1254,250（越界），中间夹一条 EXITED。**正对照之一**
#   D2 外窗上按右、再松左            → 按右**一条都没有**（它按在外窗上）；松左有行（下面第 2 行），
#                                     mex=0x1000 = 右键还按着，xy=1254,250 是外窗中心换算到面板内坐标
#   D3 只剩被挡掉那只键按着，拖回面板 → **Java 侧零条事件**，连 ENTERED / MOVED 都没有 ← 本票要的读数
#   D4 松右                          → 按下 / 松手一条都没有（它按在外窗上）；只有 ENTERED / MOVED / EXITED
#   D5 面板里按右 → 拖一段 → 松右    → PRESSED / 12 条 DRAGGED btn=3 mex=0x1000 / RELEASED（下面第 3、4 行）。
#                                     **正对照之二**：合成的右键拖动进得了 Java，所以 D3 那个零不是它造成的
#
# 结论（写回 web/src/app/App.tsx 的 onDrag、web/src/start/StartPanel.tsx 的 onMove 与
# docs/web-primitives.md）：**拖动归「起这次拖动的那只键按下时所在的那个窗口」**。起 grab 那只键
# 松开后只剩那只在窗口外按下的键按着时，原版一条都收不到。
