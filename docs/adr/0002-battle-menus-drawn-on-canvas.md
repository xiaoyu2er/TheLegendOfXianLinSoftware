# 战斗里的三个菜单画进画布，不用 React

`docs/MIGRATION-PLAN.md` 定的分工是「Pixi 画场景与战斗，React 画 UI（菜单 /
商店 / 装备 / 技能 / 对话框）」。战斗里的指令菜单、技能菜单、药品菜单正好卡在
这条线上——它们是菜单，但长在战斗里。**这三个走 Pixi，是对那条分工的
有意偏离。**

理由是判据：这三个菜单在原版里画的是**按钮贴图**，不是文字排版，而战斗要
逐像素比对。贴同一张图天然一致；用 React 加 CSS 重做，要做到每个像素相等
几乎不可能。

## Considered Options

**React 画，靠截图仍能截到它**。取图走的是 `Page.captureScreenshot` 裁
1024×640，截的是页面合成后的画面，所以 DOM 元素**确实会**被截进去——这条
路技术上通。否掉它的是像素相等这个要求，不是截不截得到。

## Consequences

**M3 的独立菜单系统同样走全 Pixi 贴图，不用 React DOM。**（决定本身在
`xl-6lo.2` 里定，这里只是把它接到本 ADR 的判据上。）

两件事把它接了过来：

- **天书页那批按钮与战斗菜单是同一种东西。** `src/menu/FuncButtons.java`
  里 `drawString` 的出现次数是 **0**（实测 2026-09-08），一颗按钮就是
  「常态 / 悬停 / 按下」三张 png；`sources/菜单/天书/` 下 **50 个文件** =
  16 颗按钮 × 三态（48）+ `主人公4人1.png` + 背景 `天书.png`。上面那条
  「贴图天然一致，CSS 重做几乎不可能像素相等」原样适用，一个字都不用改。
- **真正属于文字排版的只有三块**：三个人的属性数值、装备 / 药品的名称列表、
  技能说明。它们的像素缺口不靠「换个渲染载体」消掉，靠
  `web/src/compare/expected.ts` 的 **`gaps` 分区表态**——圈出矩形、写量出来的
  `maxPixels`，缺口补上了那张表也要跟着红。

否掉的是**混合**（贴图走 Pixi、文字层叠 DOM）：两套坐标系、两套字体，文字的
像素缺口一个都没少，却多了一层同步成本。

### 这一段原先写的是反话，为什么

本 ADR 落成时（2026-09-07 07:42，commit `04723d8`）这一段写的是：

> M3 做独立菜单系统时用 React，与这里不冲突：那批菜单不在逐像素比对的剧本里。

**那句话是错的，而且不是「后来才过期」——它写下的时候就已经错了。** 时间线是
量出来的，不是回忆的：

| 时刻 | 事件 |
|---|---|
| 2026-09-06 19:31 (`a624bce`) | `menu-equip` 真值落地（xl-1vu.5） |
| 2026-09-06 19:35 (`d5a1ea6`) | 它进 `web/src/compare/expected.ts` |
| 2026-09-06 22:09 (`091ac77`) | 四种驱动器进文档，跨端比对的接线归属写清楚（xl-1vu.7） |
| 2026-09-06 22:45 (`2cb18e6`) | `menu-magic` 真值落地（xl-1vu.9） |
| **2026-09-07 07:42** (`04723d8`) | **本 ADR 落成，写下上面那句** |

两条 menu 真值比这句话早了一整晚。写它的人（M2 的 grilling）满脑子是战斗，
把「那批菜单」当成一件尚未存在的将来事，没有回头看一眼 `traces/scripts/` ——
而那里当时已经躺着 `menu-equip.json` 与 `menu-magic.json`，
`tools/compare-frames.sh` 的原版侧四支驱动器全跑得到。

留着它的代价是具体的：`web/src/replay/implemented.ts` 的头注写着「加一个驱动器
要动的就是这里 …… 那条剧本的 `unassembled` 表态**必须**同时改成 `match` 或量
出来的 `gap`」。照着 React DOM 那条路做下去，M3 收尾时会撞上一个改不成
`match` 的表态，而那时候整个面板已经写完了。

**这条修订本身的教训**：`xl-6lo.5` 的票面转抄了「ADR-0002 立于 2026-09-07 上午，
两条 menu 真值是 xl-1vu 之后落的——那句话写下时是真的」。前半句对，
**后半句 git log 一跑就翻**。别人的时间线和别人的测量，转抄进你的文档之后长得
一模一样。
